# molframe-validate reference data

Four small files embedded into the crate (`include_bytes!` / `include_str!`),
about 350 KB in total, regenerated by `build_reference.py` (standard library
only).

| File | Content | Size |
| --- | --- | --- |
| `rama.bin` | Six Ramachandran density grids: general, Gly, trans-Pro, cis-Pro, pre-Pro, Ile/Val. 180 x 180 cells of 2 degrees, one byte per cell, `0` = absent, else `1 + round(254 * (log10(d) + 6) / 6)` | 194 KB |
| `rotamer.bin` | Seventeen chi-space classification tables (see below) | 144 KB |
| `geometry.tsv` | Backbone and side-chain bond-length and bond-angle targets with sigma | 11 KB |
| `chi_atoms.tsv` | Atom names that define chi1..chi4 per residue and the table each uses | 1 KB |

## Sources and licences

- Ramachandran and rotamer grids: Top8000 contour grids of the Richardson
  Laboratory, `https://github.com/rlabduke/reference_data`, commit
  `5ee6875fc29eccc3c9dc7cbe705ff9fd1b505d7d`
  (`Top8000_ramachandran_pct_contour_grids`,
  `Top8000_rotamer_pct_contour_grids`). Licence CC-BY-4.0; credit the
  Richardson Laboratory, Duke University. Residues come from 8000 chains at
  2.0 A or better, B <= 30 (rotamer: B <= 40), no clashes. References:
  Williams et al., Protein Sci 27:293 (2018); Hintze et al., Proteins
  84:1177 (2016).
- Bond and angle targets: Engh and Huber 1991 as tabulated in OpenStructure's
  `stereo_chemical_props.txt`
  (`github.com/metalcycling/openstructure`,
  `modules/mol/alg/src/stereo_chemical_props.txt`), LGPL-3.0. Source label
  `EH`.
- Peptide-link terms, absent from that table: C-N, CA-C-N and C-N-CA from
  `alphafold/common/residue_constants.py` (google-deepmind/alphafold, commit
  `c77e5d2a8961d1a353632c462914ff0a32a950f6`, Apache-2.0), label `AF`; O-C-N
  from the CCP4 Monomer Library `link_TRANS` and `link_PTRANS` records
  (`github.com/MonomerLibrary/monomers`, commit
  `1c97ea23a7df06373ed01cd7c3156a1f8e9b27e3`, LGPL-3.0), label `CCP4`.
- Classification thresholds follow the MolProbity implementation in
  `cctbx_project/mmtbx/validation/ramalyze.py` (commit
  `35a799409b2a9f4b9ffcf031d79153de2e1fc169`, `evalScore`): favoured at
  density >= 0.02; outlier below 0.0005 (general), 0.002 (cis-Pro) or 0.001
  (all other categories). Rotamers: favoured >= 0.02, allowed >= 0.003,
  outlier below (Hintze 2016, equal to the contour levels in the Top8000
  `Makefile`).

## Cross-check of the targets

Backbone means measured on 300 chains of the Top8000 hom50 list downloaded
from the RCSB (non-Gly, non-Pro, B <= 30, occupancy 1, 4-sigma clipped,
51932 residues): N-CA 1.460, CA-C 1.525, C-O 1.233 A, N-CA-C 110.85 degrees,
against Engh and Huber 1.459, 1.525, 1.229 and 111.0. The measured spreads
(0.010 A) are tighter than the 1991 sigmas because modern refinement
restrains to these very targets; the table keeps the published sigmas.

## Encodings

- Cell index: `phi_bin * 180 + psi_bin`, bin = `floor((angle + 180) / 2)`.
- Rotamer file: magic `MFRT`, table count, then per table: name length, name
  (lower case), dimension count, per dimension `u16 bins` and `u8 half` (1 when
  the dimension spans 180 degrees, i.e. a symmetric chi), `u32 payload length`,
  payload. The payload is run-length coded over the dense cell array (first
  dimension slowest): each run is a varint of `length << 2 | class` with class
  0 outlier, 1 allowed, 2 favoured. Cell width is the dimension span divided by
  its bins. Leu uses the table with `tt*` and `mp*` removed, Phe and Tyr share a
  table.
- `rama.bin`: magic `MFRM`, grid count, then per grid an 8-byte name and 32400
  bytes.

## Rebuilding

```sh
git clone https://github.com/rlabduke/reference_data /tmp/ref-data/rd
python3 -I build_reference.py --top8000 /tmp/ref-data/rd \
  --ost /tmp/ref-data/ost/stereo_chemical_props.txt
```
